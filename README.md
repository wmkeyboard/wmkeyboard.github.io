# wmkeyboard.github.io

Mirror of the [WM Keyboard docs](https://wmkeyboard.pages.dev), served at
<https://wmkeyboard.github.io> for networks that block `*.pages.dev`.

Built automatically from [`docs/`](https://github.com/wasi-master/wmkeyboard/tree/main/docs)
in [wasi-master/wmkeyboard](https://github.com/wasi-master/wmkeyboard) by
[`.github/workflows/mirror.yml`](.github/workflows/mirror.yml): it checks every
30 minutes and rebuilds when the source changed. Edit the docs there, not here.
